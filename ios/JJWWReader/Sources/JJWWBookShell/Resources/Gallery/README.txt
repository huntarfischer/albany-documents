JJWW EDITORIAL GALLERY

Drop research images into this folder.

Supported extensions:
- png
- jpg / jpeg
- heic
- tif / tiff

Any supported image that is not yet listed in editorial-gallery-manifest-v0.1.json is automatically discovered and appears in the developer Gallery as UNPLACED.

To promote an image into the authored manuscript flow, add a manifest entry with:
- stable id
- exact filename
- role
- title / caption / credit / alt text
- insertionStyle
- optional placement { canonicalLine, edge }

Do not infer historical placement from a filename. Placement is explicit because the manuscript order is authored evidence/pacing.

Known Stage 7 asset filenames already reserved by the manifest:
- JJWW UPDATED COVER copy.jpeg
- SYMBOL NAVY.png
- new ALBANY FIRST MAP BW CROPPED TITLE.jpg

The Albany map is the delayed in-book title plate. It must not be moved to the front simply because its role is a title.
